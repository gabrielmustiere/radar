# Kit de redesign — Radar (modèle 5, clair)

| Fichier | Rôle |
|---|---|
| `SPEC.md` | Spécification complète : intention, tokens, écrans, évolutions fonctionnelles, décisions ouvertes |
| `motion.css` | Animations prêtes à intégrer dans `assets/styles/app.css` |
| `PROMPT.md` | Prompt à donner à Claude Code pour lancer le travail |

Maquettes visuelles et prototype cliquable : canvas claude.ai « Radar — 4 directions de design », onglet **V3 · Modèle 5 clair — toutes les interfaces**.

Correspondance maquette ↔ écran : `liens` (fil et catégorie), `mobile`, `ajouter` (modale d'ajout), `reprendre`, `sources`, `extension`, `comptes`, `nouveaucompte`, `modifiercompte`, `categories` (admin), `connexion`.
